# Briefs and reports

Every brief contains task, tracker item, plan files, phase, worktree, branch, role, requested/resolved model, effort, difficulty, risk, retry, error fingerprint, objective, owned scope, forbidden scope, constraints, acceptance criteria and report format.

Developer reports changed files and checks. Tester reports exact command, exit code, duration and evidence. Reviewer reports mode, verdict, severity and file/line evidence. Only the coordinator talks to the user; managers report upward. Keep claims, code evidence, test evidence, review findings and open decisions separate.
